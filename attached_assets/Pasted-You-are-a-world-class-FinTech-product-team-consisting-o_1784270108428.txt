# FRAUD PROTECTION SYSTEM

Create an impressive fraud detection demo.


Scenario:

A suspicious withdrawal happens:

"Are you the person who requested a withdrawal of 50,000 SAR?"


Buttons:

YES

NO


If user selects NO:

Show:

"Are you sure?"

Buttons:

Confirm Fraud

Cancel


If Confirm Fraud:

AI automatically:

- Freezes bank card
- Creates fraud report
- Sends information to bank branch
- Creates replacement card request


Show messages:

"Your card has been temporarily frozen."

"Fraud report created successfully."

"Your replacement card request has been submitted."


Make this experience cinematic.
