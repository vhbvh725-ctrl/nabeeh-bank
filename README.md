#  Nabeeh Bank & Asset Manager

A modern, secure, cross-platform mobile application for digital banking and asset management designed for seamless financial tracking and intuitive navigation.

---

##  Features

* **Interactive Financial Dashboard:** Real-time analytics and dynamic control panels for asset tracking.
* **Authentication Flow:** Secure login interface with user session management.
* **Responsive Mobile UI:** Optimized components for smooth performance on both iOS and Android.
* **Modular Architecture:** Clean codebase designed for scalability and maintainability.

---

##  Tech Stack

* **Frontend:** React Native, Expo, TypeScript
* **State & Logic:** JavaScript (ES6+), React Hooks
* **Tooling:** Git, Replit Agent, GitHub Actions
